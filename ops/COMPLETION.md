Локальная реализация и проверки завершены. Публичная публикация ещё не выполнена: pilloway.eu указывает на 45.83.194.145 и отдаёт Index of /. Доступ к серверу/хостингу не предоставлен.

## Сделано
- P0: актуальный EU-код перенесён в named volume; WooCommerce загружен, Store API = 200. Есть повторяемый sync-local.py. Исправлен лимит памяти: 512M вместо вызывавших fatal 128M.
- P1/P6: перенесены отсутствовавшие плагины, изменения темы, новые платежные обработчики UA, GA4, мобильное меню и checkout. Имена каталога темы и привязки Polylang сохранены. Из различий функционального кода остаются только необходимые EU-настройки Meta и расширение сортировки категорий на шесть языков.
- P2: выполнено новое правило владельца строго в последовательности: убрать прежние скидки → +15% к исходной обычной цене → скидка 30% только для актуальных акций UA. Округление вверх до целого. Курс подтверждён er-api на 12.11.2026. Подробности и формулы в PRICING.md.
- P3: штатный выбор страны WooCommerce управляет WCPBC; включён полный список стран для billing. Адресные поля динамически появляются для зарубежных адресов. LiqPay доступен для UA/UAH, WayForPay — зарубежные EUR/USD; прежний UA-IBAN не предлагается за пределами UA. Доставка ограничивается реально настроенными зонами Nova Post.
- P4: подготовлены production URL, HTTPS-конфиг, шаблон wp-config без секретов, env example и override compose для production. admin_email заменён на существующий публичный контакт pilloway.info@gmail.com. Локальный URL сохранён.
- P5: сохранены все шесть языков, включая de; все языковые главные страницы = 200.
- P7: cookie-баннер исправлен, установлен и активирован на EU и UA; обе кнопки, сохранение выбора, повторное открытие и перезагрузка проверены. Секции cookies добавлены в privacy policy всех существующих переводов. Режим display-only сохранён согласно требованию, аналитика выбором не блокируется.
- P8: EU Google Shopping Feed адаптирован на английские карточки и EUR: 384 товара, 101 акционный; обычные/акционные цены и валюта целевых страниц проверены. Режим выбранной категории также переводит категории на английский. Исправлен общий кеш WCPBC: акционные ID корректно сопоставляются текущему языку, на каждом из шести языков проверен 101 товар. GLA настроен на 27 стран ЕС. Meta ID вынесен в опцию EU; скопированный UA ID не отправляется без решения владельца. Порог бесплатной доставки UA 5000 UAH сохранён; международные направления остаются по тарифам перевозчика в соответствии с настройками доставки.
- Медиа: перенесено 106 отсутствовавших файлов UA; обновлены фотографии у 274 EU-карточек, включая 162 галереи. Локализованные изображения сохранены. Все 2304 карточки имеют физически существующую главную фотографию.

## Результаты проверок
- Все 2304 EU-карточки, три валюты и базовые/региональные цены совпадают с расчётным манифестом; ошибок 0. 606 акционных карточек = 101 товар × 6 языков. Повторный запуск миграции проверен, наценка не накапливается.
- Все 768 UA-карточек сравнены с исходным снимком по пяти ценовым полям: изменений 0.
- В браузере: контрольный товар UA → 2003 UAH, DE → 40 EUR, US → 45 USD; доступные способы оплаты переключаются. Английский checkout показывает английские поля и описание WayForPay.
- Главная/магазин/корзина/товар, языковые главные и Store API отвечают 200. Пустой checkout штатно перенаправляет в корзину; checkout с товаром проверен отдельно в браузере.
- PHP lint функциональных плагинов и темы пройден; JS нового баннера проходит node --check. 369 runtime-файлов PHP/JS/CSS сверены с исходниками, расхождений нет (финальные правки пробелов отдельно синхронизированы и lint проверен).
- Валидация Nova Post требует email для nova_post_* и не требует его для остальных методов. Некорректные webhook-запросы LiqPay/WayForPay отклоняются с 400.
- Production-конфигурация формирует https://pilloway.eu и исключает sandbox-шлюзы. Реальные платежи не выполнялись.
- Мобильный checkout 390 px: ширина документа 390 px, горизонтальной прокрутки нет; screenshot в output/playwright/eu-checkout-mobile.png. Консоль браузера EU/UA без ошибок. PHP-лог после маркера финальной проверки без новых ошибок.

## Что требует внешних данных
1. Доступ к хостингу/SSH для публикации на pilloway.eu и проверки TLS/webhook снаружи.
2. Рабочие EU WayForPay merchant/secret (локально включён sandbox); EU-IBAN, если банковский перевод должен предлагаться зарубежным покупателям.
3. Для отправки фида в Merchant Center нужно подтвердить GTIN/MPN или отсутствие идентификаторов: сейчас у 384 товаров они не заданы; вымышленные идентификаторы не добавлены.
4. EU GA4 ID, Meta Pixel ID и при необходимости TikTok ID/CAPI token. Нужен ответ владельца, можно ли использовать существующие UA-ресурсы.

Готовые финальные дампы БД вне Git: ../backups/database-ready-eu-2026-11-12.sql и ../../pilloway-ua/backups/database-after-cookie-2026-11-12.sql. Исходные бэкапы сохранены. Инструкция публикации — DEPLOYMENT.md. Финансовые реквизиты и рекламные ID не выдуманы.
