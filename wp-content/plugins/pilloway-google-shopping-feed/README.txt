Pilloway Google Shopping Feed
==============================

Назначение
----------
Формирует XML-фид опубликованных украинских товаров WooCommerce для Google Merchant Center. Это отдельный товарный фид, не XML sitemap WordPress.

Требования
----------
- WordPress и WooCommerce.
- Polylang для отбора украинских переводов, если он установлен.
- PHP с XML-совместимым UTF-8.

Настройка
---------
Откройте WooCommerce → Google Shopping Feed.

Выбор товаров:
1. «Товары из категорий» или «Только акционные товары» — взаимоисключающие режимы.
2. Для режима категорий выберите «Все категории» или «Только выбранные категории».
3. В режиме выбранных категорий отметьте нужные категории чекбоксами.
4. Сохраните выбор. Перестроение фида ставится в очередь WordPress Cron.
5. Скопируйте защищённый Feed URL из админки в источник данных Merchant Center.

Google Shopping поля:
- Google category выбирается автоматически по названию товара; для неоднозначных позиций доступен ручной override в карточке товара.
- GTIN берётся только из штатного Global Unique Identifier WooCommerce и проверяется контрольной цифрой.
- MPN можно указать в карточке товара только если этот код действительно присвоен производителем.
- Фид не выдумывает GTIN и по умолчанию пропускает identifier_exists, если отсутствие идентификатора не подтверждено. Отметку «no» включайте только после проверки упаковки/производителя.
- SKU-утилита затрагивает только шаблонные PROM-… и 0000; действительные SKU не меняются, прежний шаблон сохраняется в метаданных.

Обновление фида
---------------
Плагин планирует полную генерацию каждые 6 часов и ставит обновления после изменения товара/остатка. WordPress Cron запускается при посещении сайта; для надёжной работы на хостинге настройте системный cron, который регулярно вызывает wp-cron.php. Например, раз в 15 минут:

curl -fsS 'https://ВАШ-ДОМЕН/wp-cron.php?doing_wp_cron' >/dev/null 2>&1

Замените ВАШ-ДОМЕН на домен сайта. Не отключайте штатный WP-Cron, пока системный cron не проверен.

Ограничения перед отправкой в Merchant Center
---------------------------------------------
Проверьте цены, наличие, изображения, GTIN/MPN и соответствие Google category в самом Merchant Center. Не добавляйте один и тот же товар одновременно из этого фида и другого источника, пока не проверили настройки Google Listings & Ads.
